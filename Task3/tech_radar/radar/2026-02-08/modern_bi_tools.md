**Modern BI Tools (т.е., Power BI)** — Инструменты бизнес-аналитики для визуализации данных, создания отчётов и дашбордов.

| Сценарий | Описание |
|--------------|--------------------------|
| **Целостное представление по ключевым показателям** | Отображение сводных данных и трендов по всем бизнес-направлениям. |
| **Самообслуживание для бизнес-пользователей** | Предоставление возможности сотрудникам создавать свои отчёты в пределах допустимых срезов данных. |
