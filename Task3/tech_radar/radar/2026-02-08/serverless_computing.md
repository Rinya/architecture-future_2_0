**Serverless Computing (т.е., AWS Lambda, Azure Functions)** — Выполнение кода без необходимости управления серверами.

| Сценарий | Описание |
|--------------|--------------------------|
| **Гибкое масштабирование финтех-сервисов** | Быстрое реагирование на пиковые нагрузки при проведении финансовых операций. |
| **Рентабельная обработка данных** | Оптимизация затрат на обработку периодических или спорадических задач по трансформации данных. |
