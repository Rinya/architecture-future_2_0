**Data Catalog (т.е., Microsoft Purview, Collibra)** — Платформы для управления метаданными, поиска, понимания и обеспечения качества данных.

| Сценарий | Описание |
|--------------|--------------------------|
| **Повышение эффективности пользователей** | Сотрудники смогут быстрее находить нужные данные для отчётов. |
| **Соблюдение требований регуляторов** | Обеспечение прозрачности и контроля над чувствительными медицинскими и финансовыми данными. |
| **Управление сложностью** | Поддержание целостного представления по ключевым бизнес-показателям в условиях роста. |
