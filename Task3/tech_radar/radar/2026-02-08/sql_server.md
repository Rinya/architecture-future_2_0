**SQL Server 2008 DWH** — Устаревшая реляционная база данных, используемая как центральное хранилище данных и центр бизнес-логики.

| Сценарий | Описание |
|--------------|--------------------------|
| **Хранение корпоративных данных** | Данные по клиентам, мед. картам (история без аналитики), финансовая история, персонал, инвентаризация.  |
| **Реализация значительной части бизнес-логики** | Это является основным ограничением. |

### Планируемые Действия
- Миграция: Поэтапный перенос данных в облачное DWH/Lakehouse. 
- Вывод из эксплуатации (DECOMMISSION): После полного переноса всех данных и бизнес-логики. 
- Обоснование: Устаревшая платформа, высокие риски безопасности, отсутствие поддержки, сложность масштабирования, смешивание операционной и аналитической логики.
