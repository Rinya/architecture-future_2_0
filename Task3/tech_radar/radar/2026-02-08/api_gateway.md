**API Gateway** — Единая точка входа для всех API-запросов, управляющая маршрутизацией, безопасностью и мониторингом.

| Сценарий | Описание |
|--------------|--------------------------|
| **Интеграция новых бизнес-направлений** | Предоставление стандартизированного и безопасного доступа к данным и функциям для партнерских систем (фарма, электроника, ИИ). |
| **Развитие финтех-сервисов** | Обеспечение надежного и масштабируемого интерфейса для банковских услуг. |
