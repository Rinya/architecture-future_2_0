**Cloud Data Warehouse / Lakehouse (т.е., Azure Synapse, BigQuery, Snowflake, Databricks)** — Масштабируемые облачные платформы для аналитической обработки больших данных.

| Сценарий | Описание |
|--------------|--------------------------|
| **Масштабирование отчётности (сотни ТБ)** | Обеспечение высокой производительности для формирования сложных отчётов, которые сейчас занимают часы. |
| **Интеграция новых дата-источников** | Гибкое подключение данных из новых направлений (фарма, электроника) без перестройки ETL. |
| **Снижение затрат на инфраструктуру** | Переход от поддержки устаревшего оборудования к облачным сервисам. |
